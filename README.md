# 云乐 · 链接变音乐

粘贴任意视频/音乐链接，自动下载并转成 MP3 存进曲库；手机浏览器打开即可播放，还支持「保存到手机」离线听。

## 启动

双击 `start_server.bat`（或命令行运行 `python server.py`），看到提示后：

- **电脑访问**：http://127.0.0.1:8770
- **手机访问**：http://192.168.8.114:8770（手机与电脑连同一个 Wi-Fi）

## 手机端使用（安卓 / iPhone 通用）

1. 手机浏览器打开上面的手机地址
2. **iPhone**：点 Safari 底部「分享」→「添加到主屏幕」，之后从桌面图标打开，全屏体验和 App 一样
3. **安卓**：Chrome 菜单 →「添加到主屏幕/安装应用」
4. 任意歌曲点右下角 `⋯` → **⬇ 保存到手机**，歌曲就存在手机本地了，断网也能播放
5. 「全部存到手机」按钮可以一键缓存整个曲库

## 功能清单

- 粘贴链接下载：抖音、B站、视频号、各类音乐网站（视频自动转 MP3）
- 曲库列表：搜索、封面、时长显示
- 播放器：播放/暂停/上下曲、进度拖动、音量、顺序/单曲循环/列表循环/随机
- 歌单：创建歌单、添加歌曲、整单播放
- 离线：歌曲可保存到手机本地（IndexedDB），离线模式自动切换
- 锁屏控制：手机锁屏/通知栏可控制播放（Media Session）

## 注意事项

- 仅限个人欣赏，请尊重版权；VIP / 加密 / DRM 内容无法下载
- 部分网站（网易云完整版、B站会员视频等）需要登录：下载时勾选「使用电脑浏览器登录状态」（需在电脑 Chrome 里登录过对应网站）
- 视频号链接有时效性，分享出来后尽快下载
- 曲库文件保存在 `music_library/` 文件夹，元数据在 `library.json`

## 技术栈

Python + Flask · yt-dlp（链接解析）· ffmpeg（转码/封面提取）· PWA（manifest + Service Worker）· IndexedDB（手机本地存储）
